# Rusted Paint

A lightweight raster graphics editor written in Rust.

Rusted Paint is an experimental open-source graphics editor inspired by classic desktop painting applications.

The project is built with Rust, using `egui` and `eframe`.

## Features

- Drawing with a brush
- Eraser tool
- Layer management
- Undo and redo
- Canvas resizing
- Custom project format (`.rpaint`)
- Export to PNG, BMP and JPEG
- Color selection and palette

## Technology

- Rust
- egui
- eframe
- image
- serde
- rfd

## Building

Make sure you have Rust and Cargo installed.

Clone the repository:

```bash
git clone https://github.com/max23980/Rusted-Paint.git
cd Rusted-Paint
```

Build:

```bash
cargo build --release
```

Run:

```bash
cargo run --release
```
